# Changelog

## 0.1.0 — 2026-11-19

- Initial explicit-state CTL evaluator for finite total transition systems.
- Added Boolean, next, eventually, globally, and until operators.
- Added fixed-point iteration certificates and a separate semantic verifier.
- Added protocol example, CLI, benchmark harness, documentation, CI, and mutation/metamorphic tests.
- Documented non-goals: no fairness, LTL/CTL*, symbolic engine, or formal verification of the verifier.
